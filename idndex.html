📊 Enviar a Google Sheets

✔ Google Sheets conectado

Sigue estos pasos una sola vez para conectar:

1

Crea un Google Sheet nuevo

Ve a sheets.new. En la fila 1 pon: Timestamp, Fecha, Placa, Intervención, Cerrado

2

Abre el Editor de Scripts

En el Sheet: Extensiones → Apps Script. Borra todo y pega esto:

const SHEET_NAME = "Hoja 1"; function doPost(e) { try { const data = JSON.parse(e.postData.contents); const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(SHEET_NAME); data.rows.forEach(row => { sheet.appendRow([ new Date().toLocaleString("es-CO"), row.fecha, row.placa, row.intervencion, row.cerrado ]); }); return ContentService.createTextOutput(JSON.stringify({ok:true})).setMimeType(ContentService.MimeType.JSON); } catch(err) { return ContentService.createTextOutput(JSON.stringify({ok:false,error:err.message})).setMimeType(ContentService.MimeType.JSON); } } function doGet(e) { return ContentService.createTextOutput("OK"); }
3

Publica como aplicación web

Implementar → Nueva implementación. Tipo: Aplicación web. Ejecutar como: Yo. Acceso: Cualquier persona. Copia la URL.

4
